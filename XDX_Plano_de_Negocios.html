Sumário Executivo

O XĐX Mercado é um ecossistema de Data-as-a-Service (DaaS) que resolve a falta de visibilidade do varejo físico. Através de um scanner inteligente e gratuito para o consumidor, capturamos dados granulares de preço e comportamento de compra (Shelf Intelligence). O modelo de negócio é baseado na monetização dupla: Publicidade Integrada (B2C) e Venda de Inteligência de Cesta (B2B).

1. Estrutura Administrativa

O projeto opera sob um modelo de Eficiência Extrema. A infraestrutura é baseada em computação sem servidor (Serverless), o que permite custos operacionais fixos próximos de zero, escalando apenas conforme o volume de usuários aumenta.

Principais Vetores de Custo:

  • Inteligência Artificial: Processamento OCR e semântico via Gemini/OpenAI.
  • Armazenamento de Dados: Manutenção da base PostgreSQL (Supabase) para análise histórica.
  • Infraestrutura: Cloud Functions e hosting via Vercel.
