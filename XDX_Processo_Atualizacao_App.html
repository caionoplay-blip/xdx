Processo de Atualização do XDX - Mercado 🚀

Este guia descreve o passo a passo completo e seguro para gerar e enviar uma nova atualização do aplicativo para a Google Play Console sempre que você fizer modificações no código.

1. Incrementar a Versão do App

A Google Play exige que toda atualização tenha um número de versão maior que a versão anterior.

⚠️ Importante: A Google Play rejeitará seu aplicativo se você tentar enviar uma atualização com o mesmo versionCode de uma versão anterior.

Abra o arquivo android/app/build.gradle e procure pelo bloco defaultConfig:

defaultConfig {
    applicationId "br.com.xdxmercado"
    minSdkVersion rootProject.ext.minSdkVersion
    targetSdkVersion rootProject.ext.targetSdkVersion
    
    // 👇 AUMENTE ESTES DOIS VALORES
    versionCode 2      // Sempre some +1 inteiro (ex: se tava 1, vai pra 2, depois 3...)
    versionName "1.0.1" // Aumente a versão pública (ex: "1.0.0" -> "1.0.1" -> "1.1.0")
}

2. Compilar e Sincronizar o Código Web

Depois de alterar o seu código (React, CSS, etc.) e subir a versão, você precisa gerar a versão final web e copiar para dentro do projeto Android.

Abra o terminal na pasta raiz (xdx-mercado) e rode o atalho que já está no seu package.json:

npm run mobile:build

O que isso faz: Esse comando roda vite build (cria os arquivos minimizados) e depois npx cap sync (injeta o código novo dentro da pasta /android).

3. Gerar o Pacote Assinado (.aab)

A Google Play exige o formato Android App Bundle (.aab) assinado com a sua chave criptográfica (xdx-production.keystore).

Via Android Studio (Recomendado e mais visual):

  1. Abra o Android Studio.
  2. Clique em Open e selecione apenas a pasta android/ do seu projeto.
  3. Aguarde o gradle carregar (barra de progresso no canto inferior direito).
  4. No menu superior, vá em Build > Generate Signed Bundle / APK...
  5. Escolha a opção Android App Bundle e clique em Next.
  6. Escolha o seu arquivo .keystore gerado anteriormente e insira a senha.
  7. Selecione a variante de release e clique em Finish.
  8. O arquivo final .aab será gerado na pasta android/app/release/.

Alternativa: Via Terminal

Se a senha já estiver configurada internamente no build.gradle, você pode gerar direto pelo terminal:

cd android
./gradlew bundleRelease

4. Enviar para a Google Play Console

  1. Acesse o Google Play Console.
  2. Selecione o aplicativo XDX - Mercado.
  3. No menu esquerdo, vá em Produção (ou em Testes Internos, se quiser testar antes de soltar para todo mundo).
  4. Clique em Criar nova versão (Create new release).
  5. Arraste e solte o arquivo .aab (que foi gerado no Passo 3) para a área de Upload.
  6. Notas de Versão: Escreva o que mudou nessa nova versão para os usuários lerem na loja.
  7. Clique em Avançar / Salvar, revise as informações e depois em Enviar para revisão.
💡 Boas Práticas de Git (Commit)
Assim que a versão for aprovada e enviada, não se esqueça de rodar os comandos do Git no terminal para salvar o novo número de versão do seu código no GitHub:

git add .
git commit -m "chore: atualiza versão para 1.0.1"
git push
