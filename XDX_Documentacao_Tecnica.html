Arquitetura de Inteligência de Varejo e Dashboards Estratégicos

1. Visão Geral do Projeto

O XĐX Mercado é uma plataforma de Inteligência de Varejo (DaaS - Data as a Service) focada em digitalizar a experiência de compra física. O sistema captura dados de etiquetas de preço via visão computacional, processa as informações em tempo real e alimenta um ecossistema de análise B2B focado em comportamento de consumo, abandono de prateleira e eficiência orçamentária.

2. Arquitetura de Software

Frontend (PWA/Capacitor) React.js com Vite para alta performance. Integrado com Capacitor para acesso nativo à câmera e recursos mobile.
Backend (Serverless) Vercel Functions (Edge & Serverless) rodando Node.js para processamento assíncrono e segurança de chaves.
Banco de Dados Supabase (PostgreSQL) com Service Role para manipulação de dados sensíveis e analytics B2B.
Computação Visual Pipeline híbrido combinando Google Gemini 1.5 Flash (6 variantes) e OpenAI GPT-4o-mini.

3. O Motor de Inteligência (Scanner)

Desenvolvemos um sistema de Resiliência Multicamadas. Ao capturar uma imagem, o backend executa uma sequência de tentativas automatizadas (Fallbacks) para garantir 99.9% de sucesso na extração dos dados.

Hierarquia de Processamento:

  • Primário: Gemini 1.5 Flash (v1beta) - Focado em latência reduzida.
  • Elasticidade: Seleção automática entre flash-latest, flash-8b e gemini-pro.
  • Failsafe: OpenAI GPT-4o-mini acionado caso todos os modelos Google retornem erro 4xx/5xx.

Protocolo de Sanitização:

Para evitar erros de ByteString causados por caracteres invisíveis nas chaves da Vercel, implementamos a camada cleanEnvVar:

const cleanEnvVar = (val) => (val || '').replace(/[^\x00-\x7F]/g, "").trim();
const apiKey = cleanEnvVar(process.env.GEMINI_API_KEY);

4. Inteligência B2B e Analytics

O sistema não apenas lê preços, ele gera Conhecimento Estratégico através de dois vetores principais:

  • Inferência de Categoria: Algoritmo semântico que classifica o produto no ato do scan (ex: Leite → Laticínios) para relatórios de afinidade.
  • Rastreamento de Abandono: Todo item escaneado nasce como is_abandoned: true. A flag só é desativada quando o usuário finaliza a compra, permitindo que o varejista saiba quais produtos são pesquisados, mas não comprados.

5. Referência de API (Servidor)

POST /api/scan

Processa imagem em Base64 e persiste o item no banco de dados com trip_id e shelf_category.

POST /api/admin

Endpoint de controle do Dashboard. Requer adminToken para retornar métricas agregadas de economia e comportamento.

GET /api/health

Monitor de integridade: verifica status do Supabase e disponibilidade de modelos IA.
